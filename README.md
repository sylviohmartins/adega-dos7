# adega-dos7

Repositório para gerenciamento e versionamento das identidades visuais da Adega dos 7.

## Estrutura

```text
assets/
└── logos/
    ├── original.png
    ├── copa-2026.png
    └── natal-2026.png
```

As revisões de cada arte são controladas pelo histórico do Git, evitando sufixos como `final`, `v2` ou `definitivo` nos nomes dos arquivos.
