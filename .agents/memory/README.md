# Memória durável — ADEGA DOS 7

Este diretório armazena apenas conhecimento de projeto verificável e útil entre sessões.

Use `.agents/rules/memory-and-context.md` antes de adicionar qualquer entrada.

Cada memória deve possuir fonte/evidência, data da última validação, escopo e condição de obsolescência quando aplicável.

Não armazene transcrições de conversa, raciocínio privado, credenciais, dados pessoais desnecessários ou estado transitório de tarefas.

Estado de execução pertence a `.agents/runs/`; provenance de uma arte específica pertence a `docs/assets/`.
